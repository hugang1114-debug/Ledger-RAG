# Experiment Cards

No experiment should run until it has a card in `experiments/cards/`.

Use one file per experiment:

```text
experiments/cards/E001-short-name.md
```

Each card must include:

- research question
- gate being addressed
- datasets and license status
- methods and baselines
- input artifacts
- output artifacts
- metrics
- failure criteria
- command/config
- cost class
- reviewer notes

## Template

```markdown
# E000: Experiment Title

## Research Question

## Gate

## Dataset and License

## Methods

## Metrics

## Failure Criteria

## Inputs

## Outputs

## Command / Config

## Cost Class

## Reviewer Notes
```
